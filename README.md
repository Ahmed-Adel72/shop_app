# 🛍️ shop_app

A modern e-commerce application built using Flutter, providing a seamless shopping experience.

# 🌟 Key Features:
* Product Management: Browse and search through a wide range of products with detailed views and filtering options.
* Shopping Cart: Easily add items to your cart, manage quantities, and proceed to checkout with real-time updates.
* Favorites/Wishlist: Save your favorite products for quick access and future purchases.
* Secure Payments: Integrated with Stripe for secure and efficient payment processing.
* User Profiles: Manage your account details, view order history, and track your points and credits.
* Responsive Design: Adapts to various screen sizes for an optimal user experience.
* Loading Skeletons: Provides a smooth loading experience with Skeletonizer while fetching data.

# 🔧 Important Packages Used:
* Dio & Retrofit: For efficient API communication and data fetching.
* Flutter Bloc: Implements the BLoC pattern for robust state management.
* GetIt: Dependency injection for managing app-wide services.
* Shared Preferences: For storing user preferences and session data.
* Cached Network Image: Efficient image loading and caching.
* Flutter Stripe: Secure payment processing integration.
* Confetti: Adds celebratory animations for successful transactions.
* Flutter ScreenUtil: Ensures responsive layouts across different devices.
* Google Fonts: Custom fonts for a polished UI.
